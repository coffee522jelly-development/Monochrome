# CAD-MD EDITOR (Ultimate Edition)

`markdown-wasm` を使用した、高速で高機能なエンジニアリング向け「CAD風」Markdownエディターです。

## 主要機能

### 1. 高性能リアルタイム・パース
WebAssembly版のMarkdownパーサー（`markdown-wasm`）を採用。大規模な文書でも入力と同時に極めて高速にプレビューが更新されます。

### 2. Mermaid & Markdown プリセット
- **Mermaid:** 12種類以上の図面テンプレート（フローチャート、シーケンス、ガントチャート、ER図、マインドマップ、Gitグラフ、タイムライン等）を即座に挿入可能。
- **Markdown:** チェックリスト、ネストされた箇条書き、3x3/5x5テーブル、LaTeX数式ブロック、注釈（Info/Warning）、折りたたみ（Details）などのスニペットに対応。

### 3. 高度な画像管理（プロパティサイドバー）
- **ドラッグ＆ドロップ:** 画像ファイルをエディターまたはプレビューにドロップして追加。
- **アセット・ストレージ:** 画像は内部で管理され、エディター内には `![alt|w=300|a=left](asset:img-1)` のような簡潔なタグのみが挿入されます。
- **サイドバー編集:** プレビュー上の画像をクリックすると右側のサイドバーにプロパティが表示され、**「代替テキスト」「幅（スライダー調整）」「配置（左・中央・右）」**をリアルタイムに変更できます。

### 4. 究極のカスタマイズ性
- **16種類のフォント:** JetBrains Mono, Fira Code などのエンジニア向け等幅フォントから、Noto Sans JP、Playfair Display などのセリフ/サンセリフ体まで選択可能。
- **10種類の外観プリセット:**
  - **TECHNICAL (CAD):** デフォルトのテクニカルなダークテーマ。
  - **BLUEPRINT:** 設計図のような青基調のスタイル。
  - **RETRO TERMINAL:** 80年代の端末風。
  - **NEON CYBERPUNK:** 鮮やかなネオンカラー。
  - **DARK ACADEMIA / SOLARIZED / MINIMAL** など多数。
- **CSSプリセット管理:** 独自のCSSを名前を付けて保存・削除可能。

### 5. 生産性向上ツール
- **Undo/Redo (Ctrl+Z):** プリセットの挿入やサイドバーでの画像調整など、すべての操作を元に戻せます。
- **ステータスバー:** 行数、単語数、文字数をリアルタイム表示。
- **オートセーブ:** 1秒ごとに内容を `localStorage` に自動保存。
- **TOC生成:** 見出し（## 以上）からクリック可能な目次を自動作成。
- **ファイルインポート:** `.md` ファイルをドラッグ＆ドロップで読み込み可能。
- **オートペアリング:** 選択範囲を引用符 `"` や括弧 `(` で自動的に囲みます。

### 6. 多彩なエクスポート
- **PDF保存:** レイアウトと縮尺を維持したまま、高品質なPDFとして出力。
- **外部保存 (Portable MD):** 画像データを末尾に参照形式で埋め込んだ、単体で共有可能なMarkdownファイルとして出力。

## 使い方

1. `index.html` をブラウザで開きます。
2. **編集:** 左側のエディターに記述します。ツールバーの「Mermaid」や「Markdown」メニューからテンプレートを活用してください。
3. **画像調整:** 挿入した画像をプレビュー側でクリックし、右側の「プロパティ」サイドバーでサイズや位置を調整します。
4. **設定:** 右端の「設定（歯車）」ボタンから、フォント、フォントサイズ、外観スタイルを自由に変更できます。
5. **保存:** 「PDF保存」または「外部保存」をクリックしてドキュメントを書き出します。

## キーボードショートカット

- `Ctrl + B`: 太字
- `Ctrl + I`: 斜体
- `Ctrl + Z`: 元に戻す (Undo)
- `Ctrl + Y` / `Ctrl + Shift + Z`: やり直し (Redo)
- `Ctrl + S`: PDF保存
- `Tab`: 4スペース挿入
- `選択 + ( / [ / { / " / ' / ` `: 選択範囲を囲む

## 使用テクノロジー
