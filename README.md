# TECH-MD EDITOR (Ultimate Edition)

`markdown-wasm` を使用した、高速で高機能なエンジニアリング向けMarkdownエディターです。
文書作成、スライド作成、ダッシュボード表示、そして高度な図面作成をこれ一つで完結させます。

## 主要機能

### 1. 高性能リアルタイム・パース
WebAssembly版のMarkdownパーサー（`markdown-wasm`）を採用。大規模な文書でも入力と同時に極めて高速にプレビューが更新されます。150msのデバウンス処理により、タイピングの滑らかさを損ないません。

### 2. 3つの表示モード
- **文書モード (Document):** 標準的なテクニカルドキュメント作成用。
- **スライドモード (Slide):** `---`（水平線）で区切られたセクションを、16:9のアスペクト比を持つカードとして表示。プレゼンテーション資料作成に最適。
- **ボードモード (Board):** 文書をグリッド状のカードとして一覧表示。全体を俯瞰するダッシュボードとして機能。

### 3. Mermaid & 豊富なプリセット
- **Mermaid:** 12種類以上の図面テンプレート（フローチャート、シーケンス、ガントチャート、ER図、マインドマップ、Gitグラフ、タイムライン等）を即座に挿入可能。
- **スライドレイアウト:** 2カラム構成、画像+説明、コード強調など、10種類のスライド専用レイアウト。
- **構成テンプレート:** ピッチデック、システム設計書、ロードマップなど、10種類のプレゼン構成テンプレート。

### 4. 高度な画像管理（プロパティサイドバー）
- **ドラッグ＆ドロップ:** 画像ファイルをエディターまたはプレビューにドロップして追加。
- **アセット・ストレージ:** 画像は内部ストレージ（AssetStore）で管理。エディター内には `![alt|w=300|a=left](asset:img-1)` のような簡潔な参照タグのみが挿入されます。
- **サイドバー編集:** プレビュー上の画像をクリックすると右側のサイドバーにプロパティが表示され、**「代替テキスト」「幅（スライダー調整）」「配置（左・中央・右）」**をリアルタイムに変更可能。文書内の同じ画像すべてに同期されます。

### 5. 多彩なエクスポート機能
- **PDF保存 (Native Print):** ブラウザの印刷機能を最適化し、1:1の精度でPDF出力。スライドの2枚組印刷（配布資料用）にも対応。
- **HTML保存 (Standalone):** CSS、JS、Base64化された画像をすべて含んだ、単体で動作するHTMLファイルを生成。オフラインプレゼンが可能。
- **画像ZIP保存:** 全スライドを1920x1080のフルHD解像度でPNG画像化し、ZIPでまとめてダウンロード。
- **外部保存 (Portable MD):** 画像データを末尾に参照形式で埋め込んだ、単体で共有可能なMarkdownファイルとして出力。

### 6. カスタマイズとUX
- **16種類のフォント & サイズ調整:** JetBrains Mono, Fira Code, Noto Sans JPなど。
- **10種類の外観プリセット:** TECHNICAL (エンジニアリング), CORPORATE, MODERN DARK, STARTUP, BLUEPRINT, PAPER など。ビジネス・技術用途に最適なスタイルを厳選。
- **日英完全対応 (I18n):** UI、メニュー、ツールチップ、テンプレートまですべて日本語と英語を切り替え可能。
- **生産性機能:** Undo/Redo (Ctrl+Z) への完全対応、オートセーブ、TOC（目次）生成、オートペアリング。

## キーボードショートカット

- `Ctrl + B`: 太字
- `Ctrl + I`: 斜体
- `Ctrl + Z`: 元に戻す (Undo)
- `Ctrl + Y` / `Ctrl + Shift + Z`: やり直し (Redo)
- `Ctrl + S`: PDF保存
- `Ctrl + P`: プレゼンテーション開始
- `Tab`: 4スペース挿入
- `選択 + ( / [ / { / " / ' / ` `: 選択範囲を囲む

- **Markdown パーサー:** [markdown-wasm](https://github.com/rsms/markdown-wasm)
